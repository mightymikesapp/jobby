# Support

Jobby is personal, local-first software and has no hosted service or support
guarantee. Before opening an issue, run `jobby doctor --json`, attach the
sanitized diagnostic output, and note the Jobby version, Python version, OS,
and exact command that failed.

Never attach a database, backup, export, resume, application material, job
description, keyring value, or unredacted log. Reproduce with a fresh
temporary Jobby home whenever possible. Use the security process in
`SECURITY.md` for vulnerabilities.
