# Security

Jobby is a local-first, single-user application. Do not include resumes,
applications, job descriptions, databases, backups, credentials, or other
personal work product in an issue or support request.

To report a vulnerability, create a private report through the repository's
available GitHub security contact or contact the repository owner directly.
Include a minimal reproduction, affected version, and whether the issue can
expose local files, keyring values, or external network credentials. Do not
send secrets in the report. If no private reporting channel is available,
open an issue containing only the words "private security contact needed".

Security reports are handled locally; Jobby does not promise a public bounty,
service-level response time, or support contract.
